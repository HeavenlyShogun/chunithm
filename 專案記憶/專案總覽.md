# 專案總覽

最後更新: 2026-09-11

## 這個專案在做什麼

本專案是 `ESP32 Penguin Controller`，目標是製作一台可用於 Chunithm 的 DIY 控制器。

控制器由 ESP32-S3 讀取硬體訊號，再透過序列埠把原始資料送到電腦端。電腦端的 `chuniio.dll` 讀取序列埠資料，轉換成 segatools/遊戲可理解的輸入格式。

## 主要組成

- `main/`: ESP32 韌體主要程式。
- `chuniio/`: Windows 端 `chuniio.dll` 原始碼，負責和 ESP32 串口溝通並輸出遊戲輸入。
- `assets/`: README 使用的硬體照片與組裝圖片。
- `artifacts/chunithm-release.zip`: 已打包的 release 檔案，可供不想自行編譯的人使用。
- `README-TW.md`: 中文說明，包含軟體、硬體、接線、設定與已知問題。
- `README.md`: 英文說明。
- `系統作業.md`: 目前已有的專案技術重點整理。
- `專案記憶/`: 本資料夾，用來保存專案進度、操作背景與接手資訊。

## 硬體背景

目前版本支援 16 鍵觸控輸入。

主要材料:

- ESP32-S3 開發板 1 片。
- MPR121 觸控模組 2 片。
- 紅外線 LED 6 顆。
- 紅外線光電晶體 6 顆。
- 1M 歐姆電阻 6 顆，用於 IR 光電晶體。
- 33 歐姆電阻 2 顆，用於 IR LED。
- 銅箔膠帶、線材、紙箱或其他外殼材料。

觸控面板使用銅箔膠帶切成 16 個互不導通的區塊。由左到右接到兩片 MPR121: 第一片接 0 到 11，第二片接 0 到 3。兩片 MPR121 的 SDA 接 ESP32 GPIO7，SCL 接 ESP32 GPIO8。

AIR 感測器使用 6 組紅外線 LED 與光電晶體面對面對齊。光電晶體由下到上依序接 ESP32 GPIO9 到 GPIO14。

## 軟體與運行背景

ESP32 韌體負責讀取:

- 16 個 MPR121 觸控輸入。
- 6 個 AIR 紅外線感測器類比輸入。

`chuniio.dll` 負責:

- 從 ESP32 的 COM port 讀取序列資料。
- 依照設定門檻轉換觸控與 AIR 輸入。
- 讓 segatools 載入並提供 Chunithm 輸入。

建置 ESP32 韌體通常使用 VSCode ESP-IDF 擴充套件，或使用:

```bash
idf.py set-target esp32s3
idf.py build
```

建置 `chuniio.dll` 使用 MSYS2/MinGW 的 32-bit GCC。README 內目前保留的核心指令是:

```powershell
'C:\msys64\mingw32\bin\gcc.exe' -shared -O2 -Wall -Wextra -std=c11 -static-libgcc -o .\chuniio\chuniio.dll .\chuniio\chuniio.c
```

segatools 需要在 `segatools.ini` 的 `[chuniio]` 區段指定:

- `path`: `chuniio.dll` 的絕對路徑。
- `com_port`: ESP32 的 COM port 數字。
- `baud_rate=2000000`。
- AIR 與觸控相關 threshold 參數。

## 已知風險與待確認事項

- 觸控線太長可能導致干擾、幽靈觸控或斷觸；建議讓 MPR121 靠近觸控面板。
- MPR121 可能因啟動供電不穩導致部分通道無反應；可嘗試在 VCC 與 GND 間加電容，或按 ESP32 的 RST 重新啟動。
- AIR 門檻值需要依實際硬體與距離校正，README 內數值是作者本機可用參考。
- `chuniio.dll` 編譯依賴本機 MSYS2/MinGW 環境，路徑可能需要依使用者電腦調整。
- 專案與實機遊戲環境、segatools 設定相關，接手者需要自行確認合法使用環境與檔案路徑。

## 接手時先看

1. 先讀 `README-TW.md`，理解硬體接線與整體流程。
2. 若只要使用，優先檢查 `artifacts/chunithm-release.zip`。
3. 若要改韌體，從 `main/` 和 ESP-IDF build 流程開始。
4. 若要改遊戲輸入轉換，從 `chuniio/chuniio.c` 開始。
5. 若調整了接線、閾值、編譯方式或已知問題，更新本資料夾的 `記憶索引.md` 與 `專案總覽.md`。
